# APIForge scope

The supplied blueprint is the product specification. The current user request expands the foundation milestone to implementation of all named modules. Work is limited to APIForge; the other six portfolio projects are excluded.

Deliver working authentication, tenant workspaces, role management, collections/folders, saved requests, environments and encrypted secrets, restricted execution, declarative assertions, history and comparisons, dashboard, scheduled monitors, analytics, deduplicated in-app alerts, OpenAPI 3 JSON import, expiring scoped report links, audit history and a restricted platform overview. Do not seed fabricated run history or uptime figures.

Local processes bind to loopback. Production infrastructure must use HTTPS, private database/Redis networking and restricted executor egress. External email delivery and public hosting require actual provider credentials and are documented separately from in-app features.
