# FluxAPI final requirements matrix

Audit date: 27 October 2026. This matrix consolidates `docs/product-blueprint.txt`, `docs/REQUIREMENTS.md`, the architecture/security/deployment documentation, the Phase 1–3 user briefs supplied as attachments, and the Phase 4–8 briefs supplied in the conversation. The detailed phase briefs are not versioned in the repository, so the IDs below are audit IDs for the normalized requirements, not identifiers from the original briefs.

`PASS` means the stated behavior has direct automated evidence or was visually checked. `PARTIAL` means some important behavior is evidenced but the full requested case set or its operating context is not. `FAIL` means a verified defect remains. `NOT VERIFIED` means the audit did not obtain enough evidence. Severity applies to the unresolved gap; `—` means no known gap for the row. Browser evidence names the test file(s), and backend evidence names the test(s) where practical. The evidence is not a substitute for an exhaustive penetration test or a manual click-through of every control.

## Evidence register

- Backend suite: `npm.cmd run test:api` — **63 passed, 532 assertions**, 14.087 seconds, using the PHPUnit SQLite in-memory configuration.
- Browser regression: `npm.cmd run test:e2e` — **27 passed, 0 failed, 0 skipped**, 5.5 minutes, after the responsive correction, against a new fail-closed E2E database.
- Focused Audit/Admin browser test: **1 passed**; the separate current 768px screenshot test: **1 passed**. The bounded performance test: **1 passed**.
- Local companion: `node scripts/companion.test.mjs` — **3 tests passed** using a loopback fixture.
- ESLint, TypeScript, PHP syntax, isolated-copy Pint, Next.js production build, npm audit and Composer audit all passed. Exact details are in `FUNCTIONAL_QA.md`.
- Source artifacts reviewed: `docs/product-blueprint.txt`, `docs/REQUIREMENTS.md`, `docs/VALIDATION.md`, `docs/UPGRADE_2_AUDIT.md`, `docs/architecture/SYSTEM.md`, `docs/security/BOUNDARIES.md`, `docs/LOCAL_EXECUTION.md`, `docs/DEPLOYMENT.md`, `docs/phase7-e2e.md`, and `docs/database/SCHEMA.md`.
